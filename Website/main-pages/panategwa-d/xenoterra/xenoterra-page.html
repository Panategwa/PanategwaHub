XenoTerra

A survival game set on Panategwa d.

Development

XenoTerra is in active development. This page is the home for game news, screenshots, release notes, and the launcher download.

Launcher

The XenoTerra launcher installs the game, keeps it updated, and starts it from one place. Download the launcher below and run it to install or update the game with one click.

Download Launcher (Windows .HTA) Download Launcher (Python)

For the Python launcher, run python xenoterra_launcher.py in the Launcher/src folder. The launcher will download/install/update/delete the game and launch it.

Release archives and manifest go in Launcher/releases/ for offline/local installs, or can be hosted remotely.
